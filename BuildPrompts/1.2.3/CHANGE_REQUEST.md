# Change Request 1.2.3

## Approved scope

- Contributors no longer submit or approve a plan separately.
- A plan remains optional supporting context attached to the dated study.
- Contributors can create the study draft from any saved plan, even when the plan is not approved.
- The member-facing study remains the only contributor submission and pastoral approval gate.
- Required study fields remain title, body, reflection, discussion question, and application.
- Existing immutable plan revisions remain available for context and audit history.

## Safety

The backend no longer requires a plan approval for study submission, scheduling, or publication in the unified flow. Existing revision and content approval bindings remain intact for historical records.

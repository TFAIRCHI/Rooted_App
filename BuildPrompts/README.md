Each **new build request** increments the patch version. Versioning does not authorize execution, additional phase scope, or external actions.

Versioned instruction documents are immutable snapshots after archival. `PHASE_TRACKER.md` and evidence reports are dynamic execution records: append real results and preserve prior evidence when reopening work. Future versions retain earlier instruction snapshots and their evidence. Root navigation points to the current version; duplicate root-level current prompts are removed. Shared `docs/` records evolve with implementation and are tied to a tested build in each evidence report.

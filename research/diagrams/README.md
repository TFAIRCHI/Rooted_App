The content state machine describes the current editable head. A Published → Draft transition leaves the earlier approved live publication intact until an approved replacement or explicit withdrawal. Cancelled is terminal for that workflow instance; an authorized new revision can start another Draft. The publication sequence distinguishes missed editorial approval from a bounded infrastructure catch-up. A provider correlation identifier is not an assumed idempotency guarantee. [Canonical approval rules](../11-collaboration-approval-and-versioning.md) and [delivery policy](../12-scheduling-sms-and-notifications.md) supply the detailed preconditions.
